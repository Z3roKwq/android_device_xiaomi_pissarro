# Device Tree for Redmi Note 11 Pro / Pro+ / Pro+ 5G (pissarro)

The Redmi Note 11 Pro / Pro+ / Pro+ 5G (codenamed _"pissarro"_) is a high-end, mid-range smartphone from Xiaomi.
It was released in November 2021.

| Memory                     | 6/8 Gb                                                                                                                         |
